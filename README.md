#  Lógica de Programación 1
##  Descripción
Este proyecto consiste en desarrollar un programa en **JavaScript** que solicita al usuario tres números, los analiza y los muestra ordenados de diferentes formas.
---

## Instrucciones del programa
El programa debe cumplir con lo siguiente:

- Solicitar al usuario **3 números** mediante `prompt`.
- Guardar los valores en variables.
- Analizar los números para:
  - Identificar el **número mayor**.
  - Identificar el **número intermedio**.
  - Identificar el **número menor**.
- Mostrar los resultados:
  - Ordenados de **mayor a menor**.
  - Ordenados de **menor a mayor**.
- Detectar si los números son iguales y mostrar el mensaje:
  > "Los números son iguales"

---

### Caso 1
**Entrada:**
